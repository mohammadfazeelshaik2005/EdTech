# PathSync AI Visual Design System Enforcement Rule

This repository contains the **permanent visual design system** for the entire PathSync AI platform.

Whenever developing or modifying code for PathSync AI:
1. Adhere strictly to the established design tokens in `css/tokens.css` and `design/tokens.json`.
2. Reuse existing component classes in `css/components.css` (`.ps-btn`, `.ps-card`, `.ps-badge`, `.ps-navbar`, `.ps-modal-dialog`, `.ps-opportunity-card`, etc.).
3. Maintain the primary brand colors (Deep teal `#0A6C58`, Dark navy `#0F172A`, Soft green `#EBF7F3` / `#10B981`, White `#FFFFFF`, Alternate `#F8FAFC`).
4. Keep the rounded aesthetics, soft shadows, pill badges, and Inter typography hierarchy.
5. Refer to `design/DESIGN_SYSTEM.md` and `design/reference/pathsync-design-reference.png` for reference guidance.
